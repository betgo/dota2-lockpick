# Pick the Lock · 开锁小游戏

Dota 2 **Dark Carnival** 迷你游戏「Pick the Lock」的浏览器复刻版。

在线试玩：https://betgo.github.io/dota2-lockpick/

## 玩法

- **开锁**：锁针转到黄/蓝条上时点击（桌面左键 / 手机点转盘）
- **黄条**：+1000 分 · **蓝条**：+1.5 秒
- 初始时间 **30 秒** · 通关目标 **6000**
- 黄/蓝条随机大小出现（前期约 34–40°，后期小条概率升高），缩小到 **0°** 才消失
- 命中后锁针**反向**
- **加速**：桌面按住右键；手机按住左下角「加速」按钮（约 **2.5 秒一圈**）
- **点空**：短暂禁点 + 减速
- **F9**：暂停（桌面）
- **音效 / BGM**：程序化 Web Audio，可静音
- **排行榜**：结束自动记入本机 Top 10

## 模式

| 模式 | 说明 |
|------|------|
| **经典** | 转速主要随分数 / 连中略升（接近原版节奏） |
| **加速挑战** | 对局时间越久，锁针基础转速越快；蓝条续命后仍会继续加速 |

开始界面可切换模式后再点「开始」。

## 手机

- 自适应布局（含刘海 / 安全区）
- 左下角圆形 **加速** 按钮：按住加速，松开停止
- 点转盘开锁

## 本地运行

```bash
python3 -m http.server 8765
# 打开 http://localhost:8765
```
